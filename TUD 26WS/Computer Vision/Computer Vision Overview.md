## How this course folder works

- **Lectures:** Numbered syllabus topics. Keep each topic's notes and lecture materials together. Numbers indicate syllabus order, not teaching weeks.
- **Exercises:** One numbered folder per exercise sheet, containing its PDF, supplied code, and any solutions you write.
- **Exam Preparation:** Revision summaries, practice questions, and exam information when available.
- **Resources:** Supplementary material used across several topics.

Existing note titles are preserved. Future topic folders are prepared but empty; an empty folder does not indicate study progress. Shared screenshots remain in the vault's Screenshots folder.

## Lectures and syllabus

### 00 — Introduction

- [Introduction slides — online](https://mlcv.cs.tu-dresden.de/courses/26-winter/cv1/00-introduction-no-videos.pdf)

### 01 — Linear and Integer Optimization

- Linear and integer optimization for computer vision
- Notes: [[Linear Programming]]
- Local slides: [[linear-programming-1.pdf|Part 1]] · [[linear-programming-2.pdf|Part 2]]

### 02 — Operators on Digital Images

- Digital images
- Point operators
- Linear operators, including convolution
- Non-linear operators, including edge and corner detection
- Notes: [[Digital Images]] · [[Operators]]
- Local material: [[01-operators.pdf|Lecture slides]]

### 03 — Machine Learning for Computer Vision

- Notes: [[Logistic Regression]]
- Local slides: [[02-mlcv-1.pdf|Logistic regression]] · [[03-mlcv-2.pdf|Deep learning for computer vision]]
- Attention and transformers for computer vision

### 04 — Classification of Digital Images

- Classification of digital images and image patches
- Supervised learning problems and inference problems

### 05 — Segmentation of Digital Images

- Image segmentation
- Semantic segmentation

### 06 — Object Recognition

- Single object recognition
- Multiple object recognition

### 07 — Object Tracking

- Single object tracking
- Multiple object tracking

### 08 — Embedding of Digital Images

- Principal component analysis
- Auto-encoders
- Variational auto-encoders
